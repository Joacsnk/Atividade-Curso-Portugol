# 100 Exercícios de Algoritmos - Gustavo Guanabara

Este repositório contém a resolução completa das 100 atividades de lógica de programação propostas pelo professor Gustavo Guanabara. O projeto foi desenvolvido utilizando o **Visualg** e abrange desde conceitos básicos de entrada e saída até estruturas de dados mais complexas.

## 🎯 Objetivo
Praticar e consolidar os fundamentos de algoritmos e lógica de programação através da linguagem Portugol.

## 🛠️ Tecnologias Utilizadas
* **Visualg 3.0**: Interpretador de algoritmos.
* **Portugol**: Linguagem base para os exercícios.

## 📂 Estrutura do Projeto
* **Exercícios**: Todos os arquivos `.alg` estão localizados na raiz do projeto para fácil acesso.
* **Enunciados**: O PDF original com a descrição de todos os 100 desafios está disponível no repositório: `exercicios-algoritmos.pdf`

## 📖 Conteúdo das Atividades
Os exercícios abordam os seguintes temas:
1. Sequências Básicas
2. Estruturas Condicionais (Se/Senão e Escolha)
3. Estruturas de Repetição (Enquanto, Repita e Para)
4. Vetores e Matrizes
5. Procedimentos e Funções

## 🚀 Como executar
1. Baixe e instale o [Visualg](http://visualg3.com.br/).
2. Clone este repositório ou baixe os arquivos.
3. Abra o Visualg e carregue o arquivo `.alg` desejado.
4. Pressione `F9` para executar o algoritmo.
